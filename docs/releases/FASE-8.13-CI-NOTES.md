# Notas técnicas de CI — Fase 8.13

## Escopo validado

- limite de bytes antes da leitura;
- limite de texto bruto;
- inspeção iterativa de estrutura;
- ordem anterior a checksum e versão;
- proteção da recepção e do retorno;
- proteção da geração de partilha e resposta;
- ausência de truncamento e persistência de recusa.

## Comandos

```bash
npm ci
npm run validate:content
npm test
npm run build
```

## Regra editorial

Exceder um limite técnico não define valor, verdade, adequação ou importância do conteúdo.
